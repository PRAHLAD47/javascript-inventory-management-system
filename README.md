# Inventory Management System

## Project Description

This is a JavaScript-based Inventory Management System developed using HTML and JavaScript. It allows users to enter product details and calculate the total inventory value.

## Technologies Used

* HTML
* JavaScript

## Features

* Add new products.
* Enter product names and prices.
* Store products in an inventory array.
* Calculate the total inventory value.
* Display inventory information.

## Project Files

* `index.html` — Provides the HTML structure.
* `inventory.js` — Contains the JavaScript code.
* `README.md` — Provides project documentation.

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a web browser.
4. Enter the product details when prompted.
