# javascript-inventory-management-system
A JavaScript-based Inventory Management System with Product Categories, Inventory Analytics, and Interactive Dashboard.

## Technologies Used

* HTML
* JavaScript

## Features

* Add new products and enter product names and prices.
* Organize products into categories.
* Track inventory and calculate total inventory value.
* View inventory analytics in an interactive dashboard.

## Project Files

* `index.html` — Provides the HTML structure.
* `inventory.js` — Contains the JavaScript code.
* `README.md` — Provides project documentation.

## How to Run the Project

1. Download or clone this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in a web browser.
